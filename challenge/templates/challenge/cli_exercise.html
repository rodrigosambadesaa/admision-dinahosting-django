Ejercicio 1 · Equivalente a PHP CLI

Fibonacci en Python y Django

Este ejercicio reimplementa el CLI PHP del repositorio original con servicios separados, límites temporales UTC, rangos invertidos y enteros sintéticos de hasta 256 dígitos.

Comando local:

python manage.py fibonacci "2026-06-01 00:00:00" "2026-06-30 23:59:59"

También admite rangos de precisión arbitraria:

python manage.py fibonacci "ts:123456789012345678901234567890" "ts:123456789012345678901234568500"

Salida JSON: current_month, current_year y custom_range, con marcas de tiempo como cadenas, igual que en PHP.

Para calcular desde el navegador mediante Django, utilice la versión procesada en el servidor. La versión JavaScript calcula sin enviar los valores al servidor.
